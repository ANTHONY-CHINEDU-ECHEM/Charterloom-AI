# Accessibility in Delivery

## Purpose
Public services must work for everyone, including people who use screen readers, magnification, voice control or keyboard only navigation, and people with cognitive impairments. Accessibility is cheapest when built in and most expensive when discovered by an audit after launch.

## Accessibility review gate
Before public release, an accessibility specialist reviews the change against WCAG 2.2 AA. The review combines automated checks with manual testing using assistive technology. Failures return to rework; approval records an accessibility audit.

## In the definition of done
Every public journey includes keyboard navigation checks, colour contrast checks, meaningful labels and testing with at least one screen reader. Content is written in plain language.

## Public sector obligations
UK public sector bodies must meet accessibility requirements for websites and mobile applications and publish an accessibility statement that lists any known issues.

## Signals in a charter
Members of the public, citizens, students, public channels, government services, education services and named accessibility regulations.
